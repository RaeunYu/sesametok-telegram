# 발신은 절대 포커스를 빼앗지 않는다

이 프로젝트의 존재 이유는 "업무 중 카카오톡 창을 띄워 두는 것이 눈에 띄는 상황"을 피하는 것이다.
그래서 모든 발신은 `background_only: true`로 보내고, 이 값을 끄는 설정은 제공하지 않는다.
백엔드의 기본 `send`도 창을 최전면으로 올리지 않지만, `background_only`는 카카오톡이 입력창을
읽을 수 있고 비어 있을 때만 Enter를 **창을 올리지 않고** 보내므로 "포커스를 뺏지 않는다"를
물리적으로 보장한다.

대가로 발신 실패율이 올라간다(`background_compose_not_empty`, `background_compose_unreadable`).
이때 클라이언트는 우회 경로를 찾지 않고 **사용자에게 창 상태를 정리해 달라고 요청**한다.
`draft` 모드는 포커스를 요구하므로 이 불변식과 양립할 수 없어 구현하지 않는다.
