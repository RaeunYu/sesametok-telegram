# 카카오톡 방 하나에 텔레그램 2인 그룹 하나를 대응시킨다

방마다 별도의 텔레그램 채팅을 두어, 그룹 제목이 곧 카카오톡 방 이름이 되고 그룹에 쓴 평문이
그 방으로 발신된다. 구성원은 **봇과 본인 둘뿐**이며, 봇과의 1:1 DM은 방 메시지가 흐르지 않는
컨트롤 패널로만 쓴다.

**기각한 대안**

- *단일 DM + 컨텍스트 전환*: 화면이 하나라 눈에 덜 띄지만, 여러 방의 메시지가 한 흐름에 섞여
  히스토리를 방 단위로 읽을 수 없다. 사용자는 이 불편을 더 크게 봤다.
- *포럼 슈퍼그룹 + 방별 토픽*: 구조는 깔끔하지만 채팅 목록에 큰 "그룹" 표면이 생기고,
  400여 개 방 규모에서 토픽 관리 비용이 이득을 넘는다.

**제약과 대가**

- 텔레그램에서 사용자↔봇 1:1 채팅은 **하나뿐**이므로 "방마다 채팅"은 그룹으로만 실현된다.
- Bot API에는 그룹 생성 메서드가 없어 **사용자가 그룹을 만들고 봇을 초대**해야 한다(방 추가 시 1회).
- 그룹에서는 privacy mode 때문에 봇이 평문을 받지 못하므로, **그룹 초대 전에** BotFather에서
  privacy를 꺼야 한다. 끄더라도 그룹은 사용자명이 없어 검색에 노출되지 않는다(일반 그룹은 공개 자체가 불가).
- 노출(exposed)은 백엔드가 소유하지만 **연결(binding)은 클라이언트 로컬**이다. 백엔드는
  텔레그램 `chat_id`를 알지 못한다.
